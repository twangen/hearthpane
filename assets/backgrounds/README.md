# HearthPane Collection

Four original AI-generated landscape images for HearthPane. These are synthetic scenes, not photographs of identified locations. Generated using the built-in image generation tool, then resized and encoded as 1280×800 WebP at quality 82 using ImageMagick. Each file is below 250 KB.

The release card loads these files from this repository at its matching release tag. They are not downloaded into Home Assistant by HACS. Internet access to raw.githubusercontent.com is required; browser caching is not an offline guarantee.

These assets are distributed with the project under its MIT license.
